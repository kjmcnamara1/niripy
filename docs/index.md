# Welcome to NiriPy!

Current version: **0.2.7**

NiriPy provides Python bindings for the [Niri](https://yalter.github.io/niri "The scrollable-tiling Wayland compositor") wayland compositor.

See the API section for generated reference documentation.

## Niri Version

The NiriPy API supports Niri Version 25.11 (b35bcae)
